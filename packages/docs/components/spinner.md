# Spinner 加载中

加载指示器组件。

## 基本用法

<component-demo code="<McSpinner />">
<McSpinner />
</component-demo>

## 尺寸

<component-demo code="<McSpinner size='sm' />
<McSpinner size='md' />
<McSpinner size='lg' />">
<McSpinner size="sm" />
<McSpinner size="md" />
<McSpinner size="lg" />
</component-demo>

## 自定义颜色

<component-demo code="<McSpinner color='#4CAF50' />">
<McSpinner color="#4CAF50" />
</component-demo>

## Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| size | `'sm' \| 'md' \| 'lg'` | `'md'` | 尺寸 |
| color | `string` | `var(--mc-primary)` | 颜色 |
